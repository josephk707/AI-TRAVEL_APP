### Bugs found and fixed during validation (not hidden, not worked around)
1. Starlette's router returns a raw 404 for unmatched paths, bypassing our exception handlers entirely → added an explicit catch-all route.
2. `httpx.ASGITransport` re-raises app exceptions by default (Starlette's `ServerErrorMiddleware` design) → set `raise_app_exceptions=False` for the one test that deliberately exercises that path.
3. `expo/no-dynamic-env-var`: dynamic `process.env[name]` access is never inlined by Metro at build time → rewrote to static `process.env.EXPO_PUBLIC_X` access.
4. `react-hooks/set-state-in-effect`: synchronous `setState` inside an effect body → restructured so `setState` only happens inside the async `.then`/`.catch`.
5. `@testing-library/react-native` v14's `render()` is async and must be awaited, or `screen` queries fail with "render function has not been called" → awaited it everywhere, plus wrapped manually-resolved promises in `act()` to eliminate act-environment warnings.
6. Missing `@types/jest` and a TypeScript `types` array gap caused ~40 false type errors in test files → installed the package and added an explicit `types: ["jest", "node"]`.
